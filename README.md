# Personal Library

This is the boilerplate for the Personal Library project. Instructions for building your project can be found at https://www.freecodecamp.org/learn/quality-assurance/quality-assurance-projects/personal-library


What is missing is the enviroment-Data. You can add it youself with a txt with 
```txt
PORT=
NODE_ENV=test
MONGO_URI=
```
in it and .env as name
Get your own MONGO_URI btw (it could also be - maybe - possible to solve the task with a .json-file as memory for the entries)

You only need PORT if the default-port is not available and NODE_ENV set to test means it starts in test-mode.
